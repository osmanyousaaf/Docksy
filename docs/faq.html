FAQ

Short answers to the questions people ask most.

Is it really free?

Yes, free forever. Docksy is Apache-2.0 licensed, with no paid tier, no feature gates, no seat limits and no telemetry. If it saves you money, you can sponsor development.

How is it different from Coolify?

Coolify is an excellent, mature project with far more integrations, and Docksy borrows ideas from it with gratitude. Docksy is narrower and aims to be simpler. Its differences are monitoring and alerting turned on by default (CPU and memory alerts, uptime checks, a status page), backups that are restore-verified, and a Claude-first design with a diagnose tool. See the comparison.

Does Docksy send my data to an AI?

No. Docksy never calls an LLM. The Claude integration runs on your machine, in your Claude Code or Claude Desktop, and talks to your Docksy with a token you create and can revoke. You can use Docksy without Claude at all.

Do I need Claude?

No. The dashboard and CLI do everything. Claude is an optional, very capable operator.

Which servers are supported?

Any modern x86_64 or arm64 Linux with systemd. Ubuntu 22.04/24.04 and Debian 12 are tested. The agent ships for linux-amd64 and linux-arm64.

Can Docksy and my apps share one server?

Yes. The installer registers the host as localhost, so you can deploy to it right away. Add more servers later.

Do deploys cause downtime?

No. The new container must be healthy before the old one is removed. If the deploy fails, the old version keeps serving. Set a healthcheckPath for the strongest guarantee.

Can I deploy docker-compose apps?

Yes, use the compose build type. Docksy runs docker compose -p docksy-<name> up -d --build.

Private GitHub repos?

Yes. Add a fine-grained token with read access to the repo. It's stored encrypted.

What happens if the Docksy control plane goes down?

Your apps keep running, because they're ordinary Docker containers with --restart unless-stopped behind the proxy on each server. You lose deploys, metrics collection and alerts until it's back. Agents just retry.

How heavy is the agent?

Under 15 MB of RAM and under 1% CPU, as a single static binary with no dependencies.

Can I migrate from Coolify / Heroku / Render?

Any app that builds from a Dockerfile, a compose file or a common Node/Python/Go/static layout deploys as is. Move your env vars, point DNS at the new server, and restore your database from a dump. Claude can help with all of it.

How can I help?

Star the repo, report bugs, improve the docs or pick up a good first issue. See CONTRIBUTING.md.
